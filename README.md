# INFINITY SPACE — Mission Trainer

Prototype de jeu éducatif pour le NASA Space Apps Challenge 2026
(défi : Build a Junior Astronaut Mission Trainer).

## L'objectif du jeu
Le joueur dirige un petit avant-poste lunaire pendant 10 jours.
Il doit garder l'équipage en vie en gérant l'eau, l'oxygène,
l'énergie, la nourriture et la protection contre les radiations.
Chaque décision a un coût et une conséquence.

## Comment lancer le jeu
1. Télécharger le projet.
2. Double-cliquer sur le fichier index.html.
3. Le jeu s'ouvre dans le navigateur. Aucune installation n'est nécessaire.

## Fichiers du projet
- index.html, style.css : l'écran du jeu
- resources.js : calculs de consommation
- mission-data.js : mission, événements et explications
- main.js, simulation.js, events.js : fonctionnement du jeu

## Valeurs et sources
Les valeurs du jeu sont des paramètres fictifs, pensés pour
l'apprentissage. Elles ne représentent pas des données NASA.
Les informations scientifiques sont accompagnées de leurs sources.
